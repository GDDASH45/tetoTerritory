# tetoDE

tetoDE is a free and open-source desktop environment for Linux.

## How to compile

Install the required dependencies:

```sh
sudo apt install build-essential pkg-config libfreetype-dev libpng-dev zlib1g-dev libbrotli-dev libbz2-dev
```

Then compile tetoDE:

```sh
make
```

The compiled desktop environment will be located at:

```text
bin/tetoTerritory
```
